## 4. Refuse list (religion + bad UX)

### Religion (do not build / list / audit as a feature)

1. Pixels / Triple Pixel / server-side pixel / CAPI-as-product  
2. MTA / first-last touch ROAS columns / Compass / incrementality / “true ROAS”  
3. Meta / Google / TikTok / Snap / Amazon **ad OAuth** (spend stays typed or CSV)  
4. Klaviyo / Recharge / CRM sync as install reason  
5. Full COGS / shipping / OpEx **P&L OS**  
6. GMV- or order-volume **pricing ladder** (stay flat **$39**)  
7. Predictive LTV AI / Profit Agent / Moby / Sidekick clone  
8. Custom BI builder replacing the desk  
9. Claiming Mcfly **replaces** Triple Whale / Polar / Northbeam  
10. Invented reviews, install counts, or “$100B GMV” social proof  

### Bad UX (do not copy)

| Pattern | Why it uninstalls |
| --- | --- |
| **Spend / ROAS wall on first open** | Looks like broken TW with blank tiles at $0 spend |
| **Dashboard soup** — KPI walls, snap grids, 12 competing cards | Cognitive load; small-shop 1-star on TW |
| **Second books** — analytics revenue ≠ Shopify Total Sales | Trust death (Northbeam/Polar discrepancy culture) |
| **“Wait 30 days for the number”** | Pixel learning; Mcfly must work day one on orders |
| **Login / Gmail / private-email walls** | Polar-class first-session brick |
| **Missing year painted as $0** | YoY / LTV-365 lie |
| **AI analyst that executes** | Scope + trust risk |
