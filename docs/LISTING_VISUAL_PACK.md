## Research takeaway (craft, not feature clones)

Premium analytics apps win listing conversion with:

1. **Hero screenshot = outcome** (big MER), not Settings  
2. **Clean KPI density** — Lifetimely-clean beats TW soup  
3. **Polaris-native** chrome  
4. **3–6 unique** 1600×900 shots; no browser chrome; no near-duplicates (4.4.4 / 4.4.5)  
5. **Realistic data** — empty states kill installs  

## Demo data for shots (built in)

1. Open app → **Demo** tab  
2. **Load 3-year sample desk** (matched sales + spend)  
3. **Turn sample desk ON**  
4. Capture with shot mode (hides sample banner):  
   `…/app?period=y3&shot=1`
