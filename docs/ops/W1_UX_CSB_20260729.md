## W1-2 — Contextual Save Bar

### Pattern used

App Bridge automatic save bar via `data-save-bar` (+ `data-discard-confirmation`) on React Router `<Form>`. Dirty native inputs show Admin Save / Discard; Discard resets the form; Save submits. Do **not** combine with programmatic `shopify.saveBar.*` on the same page.

### Got CSB (dirty settings forms)

| File | Surface | Notes |
| --- | --- | --- |
| `app/app/routes/app.settings.tsx` | Margin % + target Total ROAS | Primary CSB surface. `data-save-bar` + `data-discard-confirmation`; `onReset` syncs live BE preview state. No in-page Save button. |
| `app/app/routes/app.goals.tsx` | 12-month sales plan table | Same CSB attrs on monthly goal inputs. Copy already points at Admin save bar. |
