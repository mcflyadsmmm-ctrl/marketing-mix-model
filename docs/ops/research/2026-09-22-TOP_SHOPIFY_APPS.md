# Top Shopify apps — steal vs refuse for Mcfly’s $39 desk

**Lane:** Docs-only scout. Public sources only. No app code. Live PARKED. No Partner Submit.  
**Fetched:** 2026-09-22 (UTC).  
**Mcfly IA lock:** Overview → Orders → Customers → Spend → Goals. Growth / LTV live as Customers chips — not a sixth tab.  
**Price lock:** one plan $39/store/mo after 7-day trial. No Free plan. No GMV ladder.  
**Religion:** Shopify Total Sales ÷ entered spend = Total ROAS, or **—**. No pixels / MTA / “true ROAS” / COGS-P&L hero / Amazon / Recharge / off-Shopify BI.

**Job:** What category leaders actually do well (product craft + listing + habit), then map **STEAL** (inside the five tabs) vs **REFUSE**.

**Metric rule:** Stars / review counts / install claims below are quoted from the cited page as of fetch date. If a public page does not show a number, this doc says **not claimed**. Do not treat aggregator scrapes as App Store truth.

---

## Mcfly frame (what “earn the install” means here)

Mcfly sells a **Shopify-only order-history sales desk**. First open must paint Overview YoY + Orders / Customers depth at **$0 spend**. Spend is optional paste/CSV. SAMPLE walkthrough lives on https://mcflyads.com/demo — Admin is Live-only. Habit = written math + ActionCards + shareable one-liners, not a connector zoo.

Peers below either (A) sell LTV/profit analytics Mcfly is adjacent to, or (B) are habit/desk craft leaders whose **tactics** (empty states, SAMPLE/demo, pricing clarity, Admin density, shareables, mobile, onboarding without OAuth walls) transfer even when the product category does not.

## D. Steal vs refuse by Mcfly tab

### Overview

- **STEAL:** YoY month/quarter/year as the first viewport (Polar/TW complaint antidote: match Shopify). Today’s read + shareable close sentence (Peel digest / Klaviyo first-win). Soft dense scoreboard (PageFly mobile concern).
- **REFUSE:** Spend/ROAS tiles on first fold; P&L; pixel status; GMV badges; sixth “Home AI” panel.

### Orders

- **STEAL:** Source mix / weekend / typical order written out (Northbeam/TW mismatch antidote: Shopify `source_name`). Honest sync / truncated-today banners.
- **REFUSE:** Marketplace revenue outside Shopify; VAT-adjusted second books; COGS per order.

### Customers (Growth + LTV chips)

- **STEAL:** RFM-lite watchlist + ActionCards (Peel/RCI). First-product & promo → LTV (Lifetimely/RCI). Win-back timing in shop-owner English (RCI advice).
- **REFUSE:** Klaviyo/Meta audience export; subscription churn suites; country/tag LTV under PCD L2; full cohort BI builder.

### Spend

- **STEAL:** TrueProfit’s “paste costs → see the number” habit, but only for **ad spend** the merchant typed; empty = **—**; formula chips.
- **REFUSE:** Ad OAuth auto-sync; COGS/shipping/fees; MTA; POAS; pixel.

### Goals

- **STEAL:** Lifetimely “pacing vs target” energy as **two** soft targets (LTV + year returning $). SAMPLE stretch targets on demo canvas.
- **REFUSE:** Spend/CPA/ROAS goals; multi-goal OKRs suite; Profit Agent nudges.

## F. Top 8 steal tactics for Mcfly (priority)

1. **Three named first-run wins inside Admin** (Overview YoY → Customers “who to save” → Goals set targets) with **zero** OAuth wall — Klaviyo guided-setup pattern, TW onboarding inverted.  
2. **SAMPLE / template density on `/demo`** so the desk is screenshot-worthy before Live history fills — PageFly templates + Judge.me import energy; Live stays Live-only.  
3. **ActionCard empties (verb + floor)** on every thin/young/sync state — Judge.me dashboard verbs + RCI advice tone; never blank-as-$0.  
4. **One shareable Slack sentence per major insight** — Peel digest / shareables #99; no Slack product.  
5. **Flat $39 printed as the pricing tactic** — contrast TW GMV slider, TrueProfit overages, Peel $199+, Lifetimely order tiers.  
6. **Mobile Admin soft-dense scoreboards** — TrueProfit mobile habit without a native app; PageFly mobile-first craft.  
7. **First-product / promo → LTV explorers as the Lifetimely “breakdown”** — steal the question, refuse P&L/CAC pixel.  
8. **Spend optional paste with formula chips and — not 0×** — steal TrueProfit’s cost-upload habit shape; refuse COGS and ad OAuth.
