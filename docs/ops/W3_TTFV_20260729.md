## What a reviewer sees

### Path A — live review (SAMPLE OFF) · TTFV &lt;10 min

1. Demo (if SAMPLE left on) → amber hero → **Use my real store**.
2. Settings → margin → Admin save bar.
3. Spend → platforms → template → paste/upload.
4. Home → Total ROAS = sales ÷ spend; no SAMPLE strip; primary → Close when ready.
5. Close → Exceptions → Lock → Variance → Decision → CSV.

### Path B — practice (SAMPLE ON)

Loud strip + lock blocked on Close; listing `?shot=1` still says SAMPLE (1.1.4).
