### Phase 0 — Money at all costs (Jul 2026, adjacent)
- Build an agentic money machine (Robinhood / self-improving).
- “Don’t hold back.” Orchestrator + fleet. Self-prompting.
- Also: dropshipping, creator monetization, digital products, Cursor-autonomous income.
- **Lesson carried into McFly:** speed to cash + living master directive + self-improvement loop.

### Phase 1 — Shopify app as product (Jul 2026)
- Ship Mcfly Analytics: spend next to Shopify sales, LTV, goals; Polaris craft.
- Submit App Store; **freeze** functional changes while waiting.
- “Hands off” app; demo must match the real app.
- Religion: no pixels / MTA / true ROAS / TW clones.

### Phase 2 — Cash while waiting (Jul–Aug)
- “Is there any way for me to make money while waiting on approval?”
- Course experiments, Cursor monetization research, traffic for mcflyads.com.
- Dual door: app waitlist + custom inquire.

### Phase 3 — Custom Data Solutions is the money (Jul 29 →)
- Separate page: custom built analytics for businesses; SaaS sales reps sell high-ticket.
- Expand beyond ecommerce: spend audit, lead-gen analytics, advanced MDS.
- Pricing research: **$5–25K** then **$5–40K** bands; later MDS framed **$15–25K**.
- Interactive SAMPLE desks; privacy; custom favicon; toggle App ↔ Custom.
- “Blow enterprise away.” “Million dollar landing page.”

### Phase 4 — Anti-slop / depth (Aug)
- CFO: demos are garbage / AI slop; need drill-downs like million-dollar SaaS.
- Retail + SaaS SAMPLE desks (Pinnacle / Quorum-class depth).
- Simplify copy; let the **demo** sell; paper/sky aesthetic.
- Terafab-level craft aspiration via Cursor (not Grok-build clone).

### Phase 5 — Grok fleet era (Aug 21–28)
- “mcflyads.com to make me money” — X/Reddit 0 engagement.
- Fleet of Grok bots (Perf, SEO, Conversion, Security, Obs, Lab, Voice…).
- Custom-first: any company; marketing one module; Domo-class portals.
- Free stack only until a desk pays; cap 3 emails/day; no Apollo.
- STOP → handoff → Cursor owns site. Grok failed as builder.

### Phase 6 — Cursor OS (Aug 28 →)
- Autopsy Grok; Living Board + CURSOR_OS.
- Live v4/v5 hired desk; execute status → go site → go money.
- “Context memory runs out” → durable board + full prompt history here.
