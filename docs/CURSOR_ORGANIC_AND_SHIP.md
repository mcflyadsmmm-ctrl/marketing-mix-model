## A. Cursor at full potential — site craft swarm

Parent (Auto) orchestrates. Specialists use **explicit Grok** models (redesign default). One file owner per lane. Critic always parallel.

### Topology (per tick)

| Agent | Model | Owns | Output |
| --- | --- | --- | --- |
| **Implementer** | Grok 4.5 | One page or one CSS module | Diff only |
| **Critic** | Grok 4.5 | Rubric vs live/local | MUST / SHOULD / NICE |
| **SEO tech** | Grok or Composer | schema, sitemap, meta, CWV | Checklist + patches |
| **Visual QA** | Browser MCP + Grok | Screenshots desktop/mobile | Fail if green-mark / wrong logo / invite-only |
| **Listing counsel** | Grok | App Store copy vs live trust URLs | Paste-ready deltas |

### Million-dollar craft gates (fail = no publish)

1. Brand: M ribbon mark + “Mcfly Ads” (listing name Analytics only where honesty requires)
2. Hero budget: brand + 1 H1 + 1 lede + 1 CTA group + 1 desk visual
3. Thesis ≤3s: `sales ÷ spend`
4. No AI-slop palette (no purple kits, no cream-serif terracotta, no green CSS square mark)
5. Religion refuse block present on authority pages
6. CWV: LCP feel on mobile; reduced-motion respected
7. Live `?v=` matches intended deploy; trust URLs Free + PCD

## B. Organic ranking — what Cursor can and cannot do

### Cursor *can* (agent-executable)

| Move | How |
| --- | --- |
| Technical SEO + content hubs | Swarm above + [`SEO_ORGANIC_PLAN.md`](./SEO_ORGANIC_PLAN.md) |

| Brief guest posts / LinkedIn threads | Founder voice; refuse pixel bait |
| Track mentions | Search + spreadsheet of URLs / status |
| App Store listing ASO copy | Keywords that match religion; paste pack |
| Internal link graph | Chrome/footer/sitemap hygiene |

### Cursor *cannot* (human / capital)

| Move | Why |
| --- | --- |
| Buy or spam backlinks | Against Google guidelines; burns brand |
| Guarantee #1 rankings | Nobody can |
| Post as you on LinkedIn/X without you | Auth + reputation |
| Get featured on Shopify blog unsolicited | Relationship / Partner |
| Fake case studies | Religion + review risk |
| Click Partner MFA / Distribution / Submit | Human gates |

### Backlinks & mentions playbook (90 days)

**Principle:** Earn links with *clarity*, not link schemes. One useful page beats 50 AI posts.

| Weeks | Founder + Cursor |
| --- | --- |
| **0–1** | Google Search Console verify; submit sitemap; Bing Webmaster optional |
| **1–2** | Publish FAQ + cash-MER glossary; share 1 founder LinkedIn post (Cursor drafts, you post) |
| **2–4** | Outreach pack (10 personalized emails/week): Shopify agencies, MER/ROAS-skeptic operators, newsletters — offer calculator + thesis, ask for honest review not “link” |
| **3–6** | 2–3 podcast / “operator tools” pitches (Cursor writes 90-sec pitch) |
| **4–8** | Partner directory / “Shopify apps we use” lists — only after App Store live |
| **Ongoing** | Harvest support questions → FAQ; refresh why-pixels with sourced updates |

**Refuse for SEO:** doorway pages, spun “best Triple Whale alternative” spam, buying DR links, cloaking, keyword stuffing “true ROAS.”

**Success signals:** GSC impressions for cash MER / break-even MER rising; referral visits from 3+ real domains; zero soft-404s.
