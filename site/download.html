Keep it on your home screen

Install it once.
Read Total ROAS anywhere.

This page installs as an app (PWA) and works offline after the first load. No app store, no login — the calculator lives on your device.

  1. Chrome / Edge

    Install from the menu

    Open the browser menu and choose Install Mcfly Ads (or the install icon in the address bar). It opens in its own window.

  2. Safari · iOS

    Add to Home Screen

    Tap Share, then Add to Home Screen. Launch it like any app — the calculator runs without a connection.

  3. Offline

    Works with no signal

    A service worker caches the page after first load, so Total ROAS and break-even keep calculating on a plane, in a warehouse, anywhere.

Nothing you type leaves your device. The calculator does no tracking and stores no numbers on a server.
