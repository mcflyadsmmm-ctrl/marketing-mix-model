How install works (design partners)

  1. Join the free launch list on the homepage (or email us).
  2. We send a Shopify install link / Partner invite.
  3. Approve the app in Shopify Admin (orders read for sales totals).
  4. Enter spend → set margin → read cash MER.

Public App Store listing comes after design partners prove the desk. Until then, installs are invite-only.

What helps us help you

  • Screenshot if MER looks wrong vs Ads Manager
