The Monday budget ritual

A repeatable sequence so the meeting ends with one move — not a debate about models.

Sequence. Set margin → import spend → read Total ROAS vs break-even → cut, protect, or shift. Same order every week.

Steps

  1. Margin — confirm contribution % (or leave last week’s if unchanged).
  2. Spend — CSV for the period (MTD / last week / custom).
  3. Sales — Shopify for the same dates.
  4. Compare — Total ROAS vs break-even Total ROAS.
  5. One call — rules-based allocation: cut / protect / shift. Write it down.

Allocation language (keep it boring)

  • Cut — reduce spend where efficiency is below the floor and volume is discretionary.
  • Protect — hold spend on channels that must stay live (brand, always-on).
  • Shift — move dollars toward clearer till contribution without inventing MTA.

This is not a Bayesian optimizer. It is a finance-safe sentence you can defend.

Export memo habit End the ritual with a short memo: window, sales, spend, Total ROAS, break-even, the one move. Mcfly’s Monday Close / export memo pattern exists for this — see the live site when you ship.
