Spend onboarding

Get spend into Mcfly via Google Sheets

Order reports work with no spend file.

  1. 1 Type a channel, an amount, and a date — or paste a CSV. An Ads Manager CSV also works.
  2. 2 Columns are date, channel, amount.
  3. 3 Use the same date window as the orders you are reading.
  4. 4 Total ROAS is Shopify sales divided only by the spend you entered.

An empty cell is an em dash, not zero. Partial spend covers only what was entered. Adding spend does not change the orders. In Sheets: File → Import the blank CSV, fill those columns, then File → Download → CSV and paste it on Spend. You do not need SyncWith, Coupler, or Supermetrics.
