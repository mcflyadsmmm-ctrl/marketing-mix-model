Spend onboarding

Get spend into Mcfly via Google Sheets

No Google OAuth from Mcfly. Download a blank Day + selected-platform CSV, import it into a new Sheet, fill daily spend, download CSV, paste on Spend.

  1. 1 In the Mcfly Spend tab, check the ad platforms you actually run (Meta + Google are pre-selected).
  2. 2 Download your Mcfly blank template — or open a new Google Sheet and import that CSV.
  3. 3 In the new Sheet: File → Import → Upload → your CSV → Replace spreadsheet → Import data.
  4. 4 Fill daily spend by hand — or optionally connect SyncWith / Coupler / Supermetrics / Coefficient to these columns (you pay those tools).
  5. 5 File → Download → Comma Separated Values (.csv) → paste or import back on Spend.

Free path never requires SyncWith, Coupler, or Supermetrics. Mcfly does not claim “Works with” logos for those products. Paste/CSV alone is enough.
