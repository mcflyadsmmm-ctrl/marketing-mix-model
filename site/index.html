Add spend when you need the comparison

After the two totals. A shop with no spend file can stop there. A shop with a CSV or Ads Manager export uses these steps.

  1. Type a channel, an amount, and a date — or paste a CSV. An Ads Manager CSV also works.
  2. Columns are date, channel, amount.
  3. Use the same date window as the orders you are reading.
  4. Total ROAS is Shopify sales divided only by the spend you entered.
  • An empty cell is an em dash, not zero.
  • Partial spend covers only what was entered.
  • Adding spend does not change the orders.
